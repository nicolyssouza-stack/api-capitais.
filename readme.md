# Projeto api das capitaos - Josue

Uma API REST simples e rapida desenvolvida para consultar a capital de qualquer estado brasileiro (e do Distrito Federal) a partir da sua sigla (UF). 

Este projeto foi construido como parte da atividade pratica de **Desenvolvimento Back-end**, aplicando conceitos essenciais de Node.js, TypeScript e Express.

---

## oq eu usei

* **Node.js** — Ambiente de execucao JavaScript
* **TypeScript** — Tipagem estatica e seguranca no codigo
* **Express** — Framework para criacao das rotas HTTP
* **tsx** — Executor de arquivos TypeScript em modo de desenvolvimento

---
